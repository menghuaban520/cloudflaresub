01

怎么连接

平时用一个节点；需要指定出口时，再开启代理链。

手机设置

填写小火箭中已有的节点名称。网页不能读取手机节点列表，也不会购买或创建节点。

导出配置不会自动绑定代理链。下方操作清单会告诉你该点哪个节点，避免把入口和出口选反。
02

DNS 与通话隐私

DNS 帮你找到网站地址。不确定时，保留兼容优先。

写入配置

只填地址，程序自动补齐参数。请使用你信任且可访问的解析服务；节点域名引导仍保持默认。

这是针对 STUN 的设置，不代表全面阻止 WebRTC IP 暴露。操作清单会说明如何在小火箭里设置。

03

哪些应用走代理

默认国内直连，国外与未知网站跟随首页节点。

写入配置

按已收录域名分流，不是按 App 进程识别，可能存在漏项。微信不覆盖整个 qq.com；抖音不包含 TikTok，也不覆盖整片共享 CDN。

再细一点：指定网站的连接方式

每行一个完整域名，例如 api.example.com，仅匹配该域名。这里优先于应用选择；DNS 和局域网仍保留直连。

保存为本地 JSON 文件，下次载入继续改。不会上传；关闭页面前记得保存。
