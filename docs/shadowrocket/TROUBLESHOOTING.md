# 遇到问题，先看这一页

适用于 **Rebuild**。不要混用历史 v5 的隧道设置或排障配置。

| 现象 | 先做什么 |
| --- | --- |
| URL 下载失败 | 确认加在「配置」页；下载失败和节点连接失败是两件事。可从电脑下载 `.conf` 后传入手机 |
| 下载成功却没变化 | 确认配置已选中、首页全局路由为「配置」，断开重连 |
| 测速超时，但网页能打开 | 先核对客户端的测速方式和测试地址，不直接判定节点失效 |
| 测速和国外网页都不通 | 同节点、同网络切回保留的可用配置对照；新配置独有问题需看连接日志 |
| 微信 / 抖音 / 音乐的某项功能失败 | 找失败请求的完整域名与 DIRECT / PROXY / REJECT 命中规则，按自定义指南修正 |
| 国内服务显示本地 IP | 已收录国内服务直连，这是预期行为 |
| DNS 检测出现国内解析器 | 当前版本本地 DNS 走国内 DoH，不能仅凭国旗判断；本版不保证所有国外查询经代理 |
| 新版不好用，想恢复 | 选中原先保留的配置，再断开重连；没有保留时使用下方 beta.1 基线 |

```text

同节点同网络使用原可用配置：正常 / 异常 / 未测
失败请求的时间与域名：
相关错误和命中规则（截图或文字，打码）：
```
