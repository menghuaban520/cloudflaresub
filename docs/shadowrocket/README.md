# 花瓣 · 小火箭分流配置

**国内常用服务直连，国外与未知服务走你选择的节点。**

当前公开试用版：**Rebuild 1.0-beta.2**。适合已有 Shadowrocket 和可用节点、希望少折腾分流的新用户。使用这份配置不需要部署 Cloudflare、注册本项目账号或运行代码。

## 先分清两个东西

- **节点 / 订阅**：提供代理连接，需要你自己准备。本项目不附送节点。
- **配置**：决定哪些请求直连、哪些走代理、哪些广告域名被拦截。导入配置不会替你添加节点。

## 三步开始

**1. 添加配置。** 保留手机里原来能用的配置。复制下面的完整地址，到 Shadowrocket 的「配置」页，点添加按钮（通常为右上角 `+`）粘贴并下载。不同版本的按钮名称可能略有差异。

```text
https://raw.githubusercontent.com/menghuaban520/cloudflaresub/67e36a59d3a67411b40fd8834ebc25764ed83b5d/configs/shadowrocket-rebuild.conf
```

这是固定版本链接，不会悄悄变成另一个版本。不要把它添加到首页的节点订阅栏。下载失败也可 [打开配置文件](../../configs/shadowrocket-rebuild.conf)，从电脑保存为 `.conf` 后传到手机导入。

**2. 选中并连接。** 在配置页选中下载的文件；查看开头应为 `花瓣 Rebuild 1.0-beta.2`。回到首页，把「全局路由」设为「配置」，选择自己的可用节点，再开启连接。原来已经开启时，断开后重连一次。

**3. 确认可用。** 试微信发消息、抖音播放、酷狗听歌，再打开一个国外网页。测速数字不能单独说明网页是否能用。遇到问题先看 [常见问题](TROUBLESHOOTING.md)。

不要求为了安装本配置去打开额外隧道开关或安装解密证书。你此前手动改过的 App 设置不会被配置文件重置。

## 平时会怎样运行

| 服务或操作 | 预期行为 |
| --- | --- |
| 微信、抖音、酷狗、酷我等已收录国内域名 | 直连，使用本地网络出口 |
| ChatGPT、Google、GitHub、X、TikTok 等 | 使用首页选择的代理节点 |
| 未收录的域名 | 默认代理，少量国内长尾可能需要补充 |
| 局域网设备 | 规则允许直连，实际受 App / 系统设置影响 |
| 少量明确广告域名 | 拒绝请求，不保证去除开屏、朋友圈和信息流广告 |
| 更换住宅或备用节点 | 在首页手动选择；本配置不自动换出口 |

`DIRECT` 是直连，`PROXY` 是跟随首页节点，`REJECT` 是拦截。国外/国内是服务分类，不是准确测量每台服务器的位置。

## 想改哪里？

| 你的目的 | 操作入口 |
| --- | --- |
| 换住宅节点、换备用节点 | 首页选择节点，不修改配置正文 |
| 某个域名走错路线 | 按 [自定义指南](CUSTOMIZE.md) 添加精确覆盖 |
| 某个请求被误拦 | 先查日志中的 REJECT，再为那个完整域名添加覆盖 |
| 更新本项目 | 保留旧版，从本页获取新版本地址，作为另一份配置导入后选中 |
| 新版不适合自己的网络 | 重新选中保留的旧配置，断开重连 |

本版本不自动更新。你在手机里做的个性化修改不会自动合并到新版本，更新前需要另存一份。

## 当前验证到了哪一步

beta.1 已收到用户“能用”的反馈；beta.2 只增加 19 条国内 App 域名分流，连接和 DNS 参数与 beta.1 相同。构建一致性和离线回归检查通过。beta.2 的新增 App 功能、不同网络和机型仍需反馈，尚不标记为稳定版。

**DNS 使用加密传输，但不保证所有国外 DNS 都经代理，也不承诺系统级零泄漏。** 本地解析使用国内 DoH，普通代理域名尽量由节点解析。速度仍取决于节点和网络，本配置不解锁音乐会员或其他付费内容。
