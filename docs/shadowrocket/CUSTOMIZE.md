# 只改你需要的分流

普通使用不需要改参数。修改前，先在客户端保留当前配置副本；不要在唯一可用版本上反复覆盖。

## 手机里临时修改

打开已选配置的详情，进入「编辑纯文本」（名称以版本为准）。在 `[Rule]` 内找到「用户代理覆盖」或「用户直连覆盖」注释，在相应位置加规则。它们位于 DNS / 局域网之后、广告和默认分类之前，位置决定优先级。

```ini
# 例子：一个完整域名走代理
DOMAIN,api.example.com,PROXY
# 例子：一个完整域名走直连
DOMAIN,music.example.com,DIRECT
```

示例域名不是实际要修的网站，请替换成日志里看到的域名；不包含 `https://`、端口、路径或查询参数。保存后断开重连，检查实际请求。

`DOMAIN` 只匹配一个完整域名。`DOMAIN-SUFFIX,example.com,DIRECT` 会同时放行根域名及所有子域名，影响更大。新手优先用 DOMAIN，不为一个视频打不开就放行整片共享 CDN。

## 去广告误拦

只有日志明确显示 `REJECT` 时，才按误拦处理。为必要的完整域名加入 DIRECT 或 PROXY 覆盖，出站方式按服务实际用途选择。不要用清空全部规则或修改 `FINAL,PROXY` 的方式解决。

## 仓库维护者

手机配置里的规则带第三列策略；仓库的 `configs/rules/user-proxy.list` 和 `user-direct.list` 每行只有前两列，例如 `DOMAIN,api.example.com`，构建器自动添加策略。修改仓库后必须重建，已导入的手机配置不会自动同步。

若同一域名同时命中代理和直连覆盖，代理覆盖在前，优先生效。DNS 上游和局域网规则仍优先于用户覆盖。

不要在公开仓库填写节点密码、订阅 token 或完整私人访问日志。

## 可视化配置工坊

部署本项目后，打开首页的「花瓣 · 小火箭配置工坊」，或访问同一站点的 `/customize/`。开发时运行 `npm run dev`，访问终端给出的地址并进入该路径。

1. 选择连接方式、DNS、STUN 偏好和应用分流。默认导出的配置与 Rebuild beta.2 完全一致。
2. 下载 `huaban-custom.conf`，在手机文件中分享给小火箭或从配置页导入，然后选中它，首页全局路由使用「配置」。
3. 下载并完成配套操作清单。链式代理和 STUN 是客户端设置，网页仅生成具体步骤，导入配置不会自动应用或清除它们。
4. 需要下次继续调整时，选择「保存我的选项」，保管本地 JSON 文件；再次打开配置器后「载入选项」。刷新或关闭页面不会自动保存。

DNS 和分流选项写入配置；节点名称只用于生成链式代理操作清单。配置器不读取手机节点、不包含节点、不收集订阅或密码。生成、检查、选项载入和下载均在浏览器本地完成，仅从本站读取基础配置，不调用订阅生成 API。

「本地 DNS 经代理」是可选进阶模式，不承诺系统级零泄漏；它仍保留直连的节点域名引导。自定义 DNS 仅接受 1–3 个 HTTPS 地址，不支持输入任意配置语法。出现超时先恢复「兼容优先」。不要将开关显示或格式检查通过当成手机实测成功。

微信、抖音、酷狗按收录的域名匹配，不能覆盖每个 App 的所有请求。精确域名覆盖优先于应用选项，DNS / 局域网规则仍在最前面；直连和代理列表重复的域名会阻止导出。应用域名采用后缀匹配，用户自行添加的域名采用精确匹配。

客户端代理链方向与 STUN 操作参考：[Shadowrocket 使用手册](https://github.com/LOWERTOP/Shadowrocket)。界面名称与协议支持请以实际客户端版本为准。
