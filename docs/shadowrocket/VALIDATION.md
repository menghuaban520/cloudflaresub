# Rebuild 验证状态

2026-09-08，当前为 **1.0-beta.2 公开试用版**。

| 项目 | 证据与状态 |
| --- | --- |
| beta.1 基本连接 | 用户反馈“能用啦”；设备版本和网络类型未在本轮核实 |
| beta.2 国内 App 规则 | 静态检查 19 条新增直连规则及国外域名边界通过；新增功能尚待实机反馈 |
| beta.2 连接参数 | General / Host 与可连接的 beta.1 相同 |
| 新手说明版 | 只修改配置注释，所有生效内容与 beta.2 一致 |
| 构建与回归 | 构建一致性与 35 项离线检查通过；不是 Shadowrocket 内核模拟 |
| 下载包 | 解压后配置原文、SHA-256、文档相对链接和重复打包一致性通过 |
| Wi-Fi / 蜂窝切换、重启和唤醒 | 未验证 |
| DNS / WebRTC / IPv6 出口 | 未验证；不保证所有国外 DNS 经代理 |
| 节点故障时是否意外直连 | 参数设置已检查，实际行为未验证 |
| 稳定性、速度和耗电 | 未进行系统测量 |

历史 v5 / rc.1 / rc.2 已有用户端失败反馈，失败根因没有日志证实。Rebuild 可连接不代表已经准确定位旧版问题。
