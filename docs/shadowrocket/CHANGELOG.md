## 5.1.0-rc.2 — 2026-09-08

- 针对 rc.1 节点超时反馈，仅为两个经代理的 DoH 地址增加 `no-h3`，禁止 DNS 连接尝试 HTTP/3。保留加密、代理路径和 UDP 不支持时拒绝策略。
- 假设：默认节点的 UDP/HTTP3 能力与加密 DNS 的 HTTP/3 尝试存在兼容问题。没有手机日志证实，不能视作已定位根因。
- rc.1 与 rc.2 的运行参数仅有上述两处差异，规则、隧道路由和节点保持一致。使用同节点同网络比较实际网页与测速；若仍失败，停止此假设，获取客户端错误日志，不继续叠加参数。
- 不改变 HY2 节点传输协议，也不开放明文或系统 DNS 回退。

## 5.1.0-rc.1 — 2026-09-08

- 新增独立配置，内嵌仓库自有覆盖表和国内核心表，消除规则文件下载依赖。
- 提供关闭广告拦截的对照配置，DNS / 隧道参数保持一致。
- 新增离线构建器、输入输出 SHA-256 清单、自动检查和候选 artifact。
- 补齐安装、回退、排障和实机验收记录。
- 保留 v5 主配置 URL 和手动选节点行为。外部大规则表不包含在独立版中。
- 已知限制：尚未实机验收；此前全部超时的根因未确认；不承诺 DNS 或节点超时已经修复。
